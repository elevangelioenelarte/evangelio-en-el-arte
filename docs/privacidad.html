Política de privacidad

Última actualización: 13 de octubre de 2026.

El Evangelio en el Arte es un proyecto sin ánimo de lucro que publica cada día las lecturas de la misa en vídeo, acompañadas de arte sacro de dominio público. Esta política explica qué datos trata el proyecto, incluida su aplicación conectada a las API de Google, para qué los usa, dónde los guarda, con quién los comparte y cómo puedes pedir que se borren.

1. Responsable

Responsable del tratamiento: El Evangelio en el Arte. Contacto: elevangelioenelarte@gmail.com.

2. La aplicación y los datos de usuario de Google

El proyecto tiene una aplicación propia registrada en Google Cloud, llamada «El Evangelio en el Arte». No es una aplicación pública: no tiene usuarios externos y solo la autoriza el titular del canal de YouTube del proyecto (@ElEvangelioenelArte) con su propia cuenta de Google. Ningún espectador ni ninguna otra persona inicia sesión en ella.

Permisos que solicita y para qué se usa cada uno:

  • youtube.upload: subir los vídeos diarios de las lecturas al canal del proyecto.
  • youtube: gestionar el propio canal: crear y ordenar listas de reproducción, poner títulos, descripciones, miniaturas y traducciones de los títulos.
  • youtube.force-ssl: subir subtítulos y publicar o fijar comentarios propios del canal en sus propios vídeos (por ejemplo, el enlace al vídeo siguiente).

Datos de Google a los que accede: solo los datos del canal del proyecto necesarios para esas tareas: identificador y nombre del canal, sus vídeos, listas de reproducción, subtítulos y comentarios propios, y estadísticas públicas del canal (número de vídeos y suscriptores). La aplicación no lee correos, contactos, archivos ni ningún otro dato de la cuenta de Google, y no recoge datos de los espectadores ni de otros usuarios de YouTube.

Cómo se usan: exclusivamente para publicar y mantener el contenido del propio canal. No se usan para publicidad, no se venden, no se ceden a terceros y no se usan para entrenar modelos de inteligencia artificial.

Dónde se guardan y cómo se protegen: la aplicación guarda un único token de autorización (refresh token) como secreto cifrado de GitHub Actions, el servicio que ejecuta las publicaciones automáticas. Ese token no se muestra en registros ni se comparte. Los datos del canal que la aplicación consulta se usan en el momento y no se guardan en bases de datos.

Con quién se comparten: con nadie. Los textos bíblicos y las imágenes de arte que se publican son de dominio público y no contienen datos de usuarios. Para generar la voz y la reflexión del día se envían a la API de Gemini de Google únicamente esos textos públicos, nunca datos de usuarios de Google.

Conservación y borrado: el token se conserva mientras el proyecto publique vídeos. Se puede revocar en cualquier momento desde la configuración de seguridad de la cuenta de Google; en ese caso deja de funcionar al instante y se elimina de GitHub. También puedes pedir el borrado escribiendo al correo de contacto; se atiende en un plazo máximo de 30 días.

Uso limitado: el uso que hace esta aplicación de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. El uso de YouTube está sujeto a los Términos del Servicio de YouTube y a la Política de Privacidad de Google.

3. Lista de correo y canal de WhatsApp

Si te inscribes voluntariamente en la lista de correo diaria, se guarda tu dirección de correo y, si lo das, tu nombre. Se usan solo para enviarte cada día los vídeos nuevos y las novedades del proyecto. La base legal es tu consentimiento. Cada envío incluye un enlace para darte de baja, y al darte de baja tus datos se borran. Si te unes al canal de WhatsApp, el proyecto no ve tu número de teléfono; WhatsApp lo trata según su propia política.

4. Parroquias que piden el vídeo dominical

Si una parroquia solicita recibir el vídeo del domingo, se guardan los datos que ella misma facilita: nombre de la parroquia, localidad, correo de contacto y horario de misas. Se usan para preparar y enviar el vídeo cada semana, con base en su consentimiento, no se comparten con nadie y se conservan mientras quiera recibir el envío. Para darse de baja basta con responder a cualquier envío con la palabra BAJA.

5. Esta página web

No usa cookies ni herramientas de análisis. Está alojada en GitHub Pages, que puede registrar datos técnicos de acceso (como la dirección IP) según su propia política de privacidad.

6. Tus derechos

Puedes pedir acceso, rectificación, supresión, oposición, limitación y portabilidad de tus datos escribiendo a elevangelioenelarte@gmail.com. Si no quedas satisfecho, puedes reclamar ante la Agencia Española de Protección de Datos (aepd.es).

7. Menores

El proyecto no recoge a sabiendas datos de menores de 14 años. La lista de correo es solo para mayores de esa edad.

8. Cambios

Si esta política cambia, se publicará aquí con la nueva fecha de actualización.

Privacy policy summary (English)

El Evangelio en el Arte is a non-profit project that publishes daily videos of the Catholic Mass readings illustrated with public-domain sacred art. Its Google Cloud application is used only by the owner of the project's own YouTube channel (@ElEvangelioenelArte); there are no external users.

  • Scopes and purpose: youtube.upload (upload the daily videos), youtube (manage the channel's own playlists, titles, descriptions, thumbnails and localizations), youtube.force-ssl (upload captions and post or pin the channel's own comments on its own videos).
  • Data accessed: only the project channel's own data (channel id and title, its videos, playlists, captions, own comments and public statistics). No viewer data or data of other YouTube users is collected. No Gmail, contacts, Drive or other Google account data is accessed.
  • Use: solely to publish and maintain the channel's own content. Data is never sold, never shared with third parties, never used for advertising and never used to train AI models.
  • Storage and security: a single OAuth refresh token is stored as an encrypted GitHub Actions secret. Channel data is used at request time and not stored.
  • Retention and deletion: the token is kept while the project publishes videos. It can be revoked at any time at myaccount.google.com/permissions, after which it is deleted. Deletion requests: elevangelioenelarte@gmail.com, answered within 30 days.
  • Limited Use: this app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contacto
