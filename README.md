# El Evangelio en el Arte

Las lecturas de la misa de cada día, narradas palabra por palabra sobre obras maestras del arte sacro.

Este repositorio contiene el código que produce y publica los vídeos del canal
[@ElEvangelioenelArte](https://www.youtube.com/@ElEvangelioenelArte) de forma automática.

## Cómo funciona

Cada día, una tarea programada:

1. Lee las citas de las lecturas del día.
2. Extrae el texto de la Biblia.
3. Elige las obras de arte que ilustran cada pasaje.
4. Genera la narración y monta un vídeo por lectura.
5. Comprueba que la narración coincide palabra por palabra con el texto.
6. Publica los vídeos.

## Fuentes

- **Texto bíblico:** Santa Biblia libre para el mundo, de dominio público. No es el texto litúrgico oficial.
- **Imágenes:** obras de dominio público de museos, acreditadas en cada vídeo.
- **Narración y montaje:** realizados con inteligencia artificial.
